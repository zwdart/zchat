# zchat 截图与贴图功能规划

- 文档版本：v0.1（规划稿）
- 日期：2026-11-08
- 状态：待评审，暂不修改代码
- 关联文档：
  - [项目规划](SCREENSHOT_PROJECT_PLAN.md)
  - [技术规划](SCREENSHOT_TECH_DESIGN.md)

## 1. 产品定位

目标是提供一套“聊天场景下够用、操作接近 Snipaste”的截图工具，而不是完整的专业图像编辑器。用户可以在不离开 zchat 的情况下完成：

**截图 → 选区 → 标注 → 复制/保存/贴图/发送**。

设计原则：

1. **快**：快捷键触发，默认进入标注，常用动作一键完成。
2. **准**：高 DPI、多显示器、窗口边界和像素颜色准确。
3. **不打断**：截图时隐藏 zchat，完成后恢复原窗口和会话。
4. **可预期**：平台差异和权限问题提前说明，失败有明确出口。
5. **隐私优先**：截图只在本机处理，不经过服务器。
6. **渐进增强**：核心能力三平台一致；系统限制导致的能力差异明确标注。

## 2. 平台能力矩阵

| 能力 | Windows | macOS | Linux X11 | Linux Wayland |
| --- | --- | --- | --- | --- |
| 全屏截图 | 支持 | 支持 | 支持 | 支持（门户/工具） |
| 前置选区 overlay | 支持 | 支持 | 支持 | 不支持，先截图后标注 |
| 拖动选区 | 支持 | 支持 | 支持 | 标注窗口内裁剪 |
| 窗口自动识别 | 支持 | 支持 | 支持 | 不支持 |
| 窗口控件级识别 | P1 | P1 | P1（AT-SPI） | 不支持 |
| 多显示器 | 支持 | 支持 | 支持 | 取决于门户/工具 |
| 混合 DPI | 支持 | 支持 | 支持 | 取决于合成器 |
| 放大镜/取色 | 支持 | 支持 | 支持 | 支持（截后编辑） |
| 全局快捷键 | 支持 | 支持 | 支持 | MyGo 门户支持时可用 |
| 贴图置顶 | 支持 | 支持 | 支持 | 支持（受合成器限制） |
| 光标捕获选项 | 支持 | 支持 | 支持 | 通常不支持 |
| 系统权限 | 无 | 屏幕录制权限 | X11 无额外权限 | 门户授权 |

> 说明：Wayland 不允许普通应用在截图前读取全局屏幕并绘制覆盖层，因此采用“系统门户/外部工具先获得图像，再由 zchat 打开标注窗口”的降级流程。标注、复制、保存、发送、贴图能力不受影响。

## 3. 入口设计

### 3.1 聊天页入口

在输入区按钮行增加一个截图按钮，位置建议在“发送图片”和“发送文件”之间：

```text
[截图] [图片] [文件] [共享链接]                    [发送]
```

- 图标：裁剪/截图样式，24 点网格线性图标。
- 提示文字：`截图`。
- 点击：开始截图；如果当前没有会话，仍可截图，但“发送”动作禁用并提示先打开聊天。
- 截图完成后如果当前会话存在，工具栏显示“发送到当前会话”。

### 3.2 文件菜单

在“文件”菜单增加：

- `截图…`（全局快捷键显示在旁边）
- `截图并发送…`（可选，P1）

### 3.3 托盘菜单

在托盘菜单增加：

- `截图`
- `显示全部贴图`
- `关闭全部贴图`（有贴图时）
- `恢复贴图鼠标交互`（有鼠标穿透贴图时）

### 3.4 全局快捷键

- 默认：`F1`，与 Snipaste 习惯一致。
- 可在设置中修改。
- 注册失败（被占用、Wayland 旧桌面不支持）时：
  - 不阻塞应用启动；
  - 设置页显示错误；
  - 提示可通过菜单、聊天页按钮或桌面快捷键触发。
- 可选第二快捷键：`F3` 从剪贴板贴图（P1）。

### 3.5 命令行/第二实例（P1）

支持 `zchat --capture` 作为第二实例参数：

- 已运行的 zchat 收到后开始截图；
- 便于 Wayland 用户把命令绑定到桌面快捷键；
- 不改变现有单实例行为。

## 4. 截图流程

### 4.1 标准流程（Windows/macOS/X11）

1. 用户按快捷键或点击入口。
2. 如果已有截图会话，先取消旧会话，避免叠加。
3. 记录主窗口是否可见、当前页面、当前会话和焦点。
4. 隐藏 zchat 主窗口；如果贴图默认参与截图，则保留贴图，否则一并临时隐藏。
5. 等待合成器完成一帧（约 50～100ms），避免截到 zchat 自己。
6. 截取鼠标所在显示器；同时枚举窗口边界。
7. 打开全屏 overlay，显示截图、暗色遮罩、十字光标和提示。
8. 用户选择区域或窗口，进入标注状态。
9. 用户执行复制、保存、贴图、发送或取消。
10. 关闭 overlay，恢复主窗口/焦点，显示结果提示。

### 4.2 Wayland 流程

1. 用户按快捷键或桌面绑定命令。
2. zchat 请求 `xdg-desktop-portal` 截图，或调用可用的 `grim`/`gnome-screenshot`/`spectacle`。
3. 系统可能弹出授权或区域选择界面。
4. zchat 获得全屏或区域 PNG。
5. 打开普通无边框标注窗口（不要求前置覆盖整个桌面）。
6. 用户在图像上裁剪、标注、复制、保存、发送或贴图。
7. 关闭标注窗口，恢复主窗口。

### 4.3 取消与失败

| 情况 | 行为 |
| --- | --- |
| 用户按 Esc | 关闭 overlay，丢弃临时截图，恢复主窗口 |
| 用户点击取消 | 同上 |
| 截屏失败 | 关闭 overlay，提示错误，恢复主窗口 |
| 权限拒绝 | 显示权限说明和“打开系统设置”/“重试” |
| Wayland 门户取消 | 静默恢复，不显示错误 |
| 保存失败 | 保留 overlay 和截图，提示选择其他目录 |
| 剪贴板失败 | 保留 overlay，提示重试或改用保存 |
| 发送失败 | 保留截图，提示传输服务问题，可改为保存 |

## 5. 选区功能

### 5.1 拖动选区

- 在任意位置按下左键开始选区。
- 支持从左下、右下、右上等任意方向反向拖动。
- 选区实时显示尺寸：`宽 × 高`，单位像素。
- 选区外区域变暗，选区内保持原亮度。
- 选区边框使用主题强调色，1～1.5 DIP。
- 选区过小（小于 3×3 像素）视为单击，不生成空截图。

### 5.2 八向手柄

选区完成后显示 8 个手柄：

- 左上、上、右上、右、右下、下、左下、左。
- 拖动手柄调整选区。
- 拖动选区内部移动整个选区。
- 方向键微调 1 像素；`Shift+方向键` 调整大小 1 像素；`Ctrl+方向键` 10 像素（可配置）。
- 选区不能超出当前显示器的可用截图范围；跨屏能力见 5.7。

### 5.3 单击选择窗口

- 未开始拖动时，鼠标移动高亮鼠标下的顶层窗口。
- 单击左键选中该窗口边界。
- 选中后仍可拖动手柄微调。
- `Tab` 在鼠标位置的窗口栈中循环切换（P1）。
- 双击空白处选择全屏。
- 窗口边界优先使用系统报告的可见边框，避免把透明阴影算进去：
  - Windows：DWM 扩展边框；
  - macOS：CGWindow bounds；
  - X11：窗口几何 + `_NET_FRAME_EXTENTS`。

### 5.4 吸附

- 拖动选区或调整手柄时，自动吸附到：
  - 显示器边缘；
  - 窗口边缘；
  - 其他窗口边缘（P1）；
  - 屏幕中心线（可选）。
- 吸附阈值默认 8 DIP，可在设置中关闭。
- 按住 `Alt` 临时禁用吸附。
- 吸附时显示辅助线。

### 5.5 放大镜

- 默认开启，位置跟随鼠标，靠近边缘时自动翻转。
- 放大倍率：8×/12×/16×，默认 12×。
- 显示：
  - 放大后的像素网格；
  - 当前像素坐标（物理像素）；
  - 十六进制颜色值，如 `#3A7BD5`；
  - 当前选区宽高。
- 快捷键 `M` 切换放大镜。
- 取色：按 `C` 复制当前像素颜色值（P1）。

### 5.6 全屏/上一区域

- 双击空白处：选择当前显示器全屏。
- `Ctrl+A`：全屏（P1）。
- `R`：恢复上一次成功截图的区域（P1）。
- 延时截图：设置 0/3/5/10 秒，倒计时显示在屏幕中央（P1）。

### 5.7 多显示器

首版策略：

- 快捷键触发时，以鼠标所在显示器为目标。
- 每台显示器单独截图、单独映射 DPI，避免混合缩放错位。
- 可以在任意显示器上触发并完成截图。
- 暂不支持一次拖动跨越两台显示器。

后续策略：

- 为每台显示器创建独立 overlay，共享选区模型；
- 鼠标跨屏时切换到对应 overlay，选区坐标统一到全局 DIP；
- 最终按每台显示器的物理像素分别裁剪并拼接；
- 混合 DPI 下保持像素级准确。

## 6. 标注工具

### 6.1 工具栏布局

工具栏跟随选区显示，优先放在选区下方；空间不足时放到上方；再不足时放到选区内部。选区很小或靠近屏幕边缘时，工具栏可自动换行或贴边。

建议分组：

```text
[选择] | [矩形] [椭圆] [箭头] [直线] [画笔] [荧光笔] [文字] [马赛克] [橡皮] | [撤销] [重做] | [复制] [保存] [贴图] [发送] [更多] [取消]
```

- 工具按钮使用图标 + 悬停提示。
- 当前工具高亮。
- 颜色、线宽、字号使用弹出面板。
- 窄屏时“更多”收纳低频动作（另存为、历史、OCR）。

### 6.2 P0 工具

| 工具 | 行为 | 快捷键 | 备注 |
| --- | --- | --- | --- |
| 选择/移动 | 选中已有标注，拖动移动；空白处拖动移动选区 | `V` | 默认工具 |
| 矩形 | 拖动绘制空心矩形，可设置线宽/颜色 | `R` | 填充模式 P1 |
| 椭圆 | 拖动绘制空心椭圆 | `E` | |
| 箭头 | 从起点拖到终点，自动生成箭头头部 | `A` | |
| 直线 | 从起点拖到终点 | `L` | |
| 画笔 | 自由绘制平滑曲线 | `P` | |
| 荧光笔 | 宽而半透明的颜色笔触 | `H` | 叠加模式 |
| 文字 | 点击定位后输入文字 | `T` | 单行，P1 多行 |
| 马赛克 | 在区域上拖动，像素化遮挡 | `M` | 块大小可调 |
| 橡皮 | 点击/划过标注将其删除 | `X` | 删除对象，不是擦像素 |
| 撤销 | 撤销上一步操作 | `Ctrl+Z` | 至少 100 步 |
| 重做 | 重做 | `Ctrl+Shift+Z` / `Ctrl+Y` | |

### 6.3 P1 工具

| 工具 | 行为 |
| --- | --- |
| 模糊 | 对区域做高斯/盒式模糊 |
| 编号 | 自动递增的数字圆点，适合步骤说明 |
| 高亮矩形 | 半透明填充矩形 |
| 多行文字 | 支持换行、对齐、背景色 |
| 取色器 | 复制/应用到标注颜色 |
| 标尺 | 测量像素距离 |
| OCR | 识别选区文字并复制（依赖系统/外部引擎） |

### 6.4 颜色与线宽

- 预设颜色：红、橙、黄、绿、蓝、紫、黑、白。
- 自定义颜色：HSV 色轮或十六进制输入（P1）。
- 线宽：1、2、3、5、8 像素（按截图物理像素计算）。
- 文字字号：12、14、16、20、24、32。
- 荧光笔透明度：30%～70%。
- 马赛克块大小：4、8、12、16、24 像素。
- 工具设置在当前截图会话内保持；跨会话记忆作为 P1。

### 6.5 标注编辑

- 新标注默认处于选中状态，可拖动、删除。
- 选中标注显示包围框和删除按钮。
- `Delete`/`Backspace` 删除选中标注。
- 拖动标注时显示对齐辅助线（P1）。
- 双击文字标注进入编辑（P1）。
- 右键标注：删除、置顶、置底（P1）。
- 所有操作进入撤销栈。

### 6.6 文字输入

- 点击画布后出现插入光标。
- 输入框位置与最终文字位置一致，支持中文输入法。
- `Enter` 确认，`Esc` 取消，`Shift+Enter` 换行（P1）。
- 文字颜色、字号从当前工具设置读取。
- 导出时使用与预览一致的字号和颜色。

### 6.7 马赛克

- 在选区上拖动生成矩形马赛克区域。
- 块大小决定不可读程度，默认 8 像素。
- 多次覆盖不重复叠加，取最上层效果。
- 马赛克只影响导出图像，不修改原始截图。
- P1 增加模糊和“仅马赛克人脸/文字”的智能模式（可选）。

## 7. 完成动作

| 动作 | 默认快捷键 | 行为 |
| --- | --- | --- |
| 复制 | `Enter` / `Ctrl+C` / 双击选区 | 将裁剪并标注后的 PNG 写入剪贴板 |
| 保存 | `Ctrl+S` | 保存到设置的截图目录，文件名自动生成 |
| 另存为 | `Ctrl+Shift+S` | 打开系统保存对话框 |
| 贴图 | `Ctrl+T` / 工具栏图钉 | 创建置顶贴图窗口 |
| 发送到聊天 | `Ctrl+Enter` | 发送到当前会话；没有会话时提示 |
| 取消 | `Esc` | 放弃本次截图 |
| 更多 | - | 历史、OCR、复制颜色、打开保存目录 |

### 7.1 复制

- 使用 PNG 格式，保留透明度和颜色。
- 写入失败时保留截图并提示。
- 可选“复制后自动关闭”设置，默认开启。
- 可选“复制后自动保存”设置，默认关闭。

### 7.2 保存

- 默认目录：`图片/xin.dart.zchat`（可通过设置修改）。
- 文件名：`zchat-20261108-143012.png`。
- 同名文件追加 `-1`、`-2`，不覆盖。
- 保存成功后提示完整路径，可在文件夹中显示。
- 失败时保留 overlay，允许重选目录。

### 7.3 发送到聊天

- 仅在存在当前会话时可用。
- 将最终 PNG 写入 `缓存目录/screenshots/`，交由现有 `sendFiles` 发送。
- 自动识别为图片消息，沿用现有的 TCP/HTTP 传输、进度、断点续传和图片缓存。
- 发送后恢复主窗口并保持当前会话。
- 若传输服务未启动，按现有逻辑尝试启动；失败则提示并可改为保存。
- 没有当前会话时：按钮禁用，提示“先打开一个聊天”；或 P1 弹出会话选择器。

### 7.4 历史（P1）

- 记录最近 50 张截图（可配置）。
- 只保存最终 PNG 和尺寸、时间、来源显示器等元数据。
- 可从历史重新复制、贴图、发送、删除。
- 默认保留 7 天，可清空。
- 历史不参与聊天附件令牌，不自动上传。

## 8. 贴图功能

### 8.1 基本行为

- 每张贴图是独立窗口：
  - 无边框；
  - 透明背景；
  - 始终置顶；
  - 不显示在任务栏；
  - 可跨工作区显示（平台支持时）；
  - 保持图片原始比例。
- 支持同时存在多张贴图。
- 关闭主窗口时贴图是否保留：建议保留，直到用户关闭或退出应用。
- 退出应用时关闭全部贴图。

### 8.2 交互

| 操作 | 行为 |
| --- | --- |
| 拖动图片 | 移动贴图窗口 |
| 拖动边缘/角 | 缩放，保持比例 |
| `Ctrl+滚轮` | 缩放贴图 |
| `Ctrl+Shift+滚轮` 或菜单 | 调整不透明度 |
| 双击 | 关闭贴图（可配置） |
| 右键 | 菜单：复制、保存、另存为、不透明度、鼠标穿透、关闭、关闭全部 |
| `Esc` | 关闭当前聚焦贴图（可配置） |

### 8.3 鼠标穿透

- 菜单切换 `鼠标穿透` 后，贴图不再接收鼠标事件，方便覆盖在参考内容上。
- 穿透状态下无法直接点中贴图，需要通过托盘“恢复贴图鼠标交互”或全局快捷键恢复。
- 建议给穿透贴图一个短暂的边框提示，避免用户忘记。

### 8.4 贴图来源

- 截图完成后“贴图”。
- 剪贴板图片贴图（P1，默认 `F3`）。
- 聊天中的图片“贴到屏幕”（P2）。

### 8.5 限制

- 贴图窗口在 Wayland 下不能保证绝对定位到屏幕任意坐标，由合成器决定；首版按合成器允许的方式显示。
- 贴图不参与截图时，是否隐藏由设置决定。
- 贴图不写入聊天记录，除非用户主动发送。

## 9. 设置项

在现有设置窗口增加“截图”分组：

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 启用截图 | 开 | 关闭后隐藏聊天页按钮和菜单入口，并注销快捷键 |
| 截图快捷键 | `F1` | 可输入/录制组合键；显示注册状态 |
| 贴图快捷键 | `F3`（P1） | 从剪贴板贴图 |
| 截图保存目录 | `图片/xin.dart.zchat` | 支持选择目录 |
| 保存格式 | PNG | P1：JPEG/WebP |
| 图片质量 | 高 | 仅 JPEG/WebP |
| 复制后关闭 | 开 | |
| 复制后自动保存 | 关 | |

## 11. 视觉规范

- overlay 使用应用主题色，但截图内容本身不做主题化。
- 选区边框：强调色，1.5 DIP，带轻微外发光以避免深色背景看不清。
- 遮罩：黑色，透明度默认 45%。
- 工具栏：圆角 10～12 DIP，半透明深色/浅色毛玻璃背景，保证在任意截图上可读。
- 放大镜：圆角方形，带 1px 边框、像素网格和底部信息条。
- 尺寸标签：选区左上或右上，深色半透明底、白色文字。
- 手柄：8 个 8×8 DIP 的方块，白色填充 + 强调色边框。
- 标注默认颜色：红色；文字默认红色；线宽默认 2 像素。
- 所有图标使用现有 `ui.SVG` 图标体系，24 点网格、线性风格。
- 动画保持克制：工具栏出现 120ms，选区不添加延迟动画。

## 12. 错误与权限体验

### 12.1 macOS 屏幕录制权限

首次触发截图时：

- 调用系统预检接口；
- 如果未授权，显示对话框：
  - 标题：`需要屏幕录制权限`
  - 说明：`zchat 需要读取屏幕内容才能截图。请在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 zchat。`
  - 按钮：`打开系统设置`、`稍后`、`重试`。
- 授权后旧版 macOS 可能需要重启应用，界面说明这一点。
- 不把权限失败当成崩溃或静默失败。

### 12.2 Linux Wayland

- 门户未安装：提示安装 `xdg-desktop-portal` 及桌面后端，或使用 X11 会话。
- 门户取消：静默返回。
- 门户返回错误：显示可读错误，建议使用外部工具或 X11。
- 无 `grim`/`gnome-screenshot`/`spectacle`：提示当前桌面暂不支持自动截图。

### 12.3 快捷键冲突

- 设置页显示“快捷键已被占用”。
- 提供“重新输入”和“恢复默认”。
- 保存失败不阻塞其他截图入口。

### 12.4 其他错误

| 错误 | 提示 |
| --- | --- |
| 无可用显示器 | `没有找到可截图的显示器` |
| 截图返回空图像 | `截图失败，请重试` |
| 图片过大/内存不足 | `截图过大，无法处理`，建议降低分辨率 |
| 保存目录不可写 | 提示选择其他目录 |
| 剪贴板不可用 | 提示改用保存或重试 |
| 文件传输服务未启动 | 复用现有提示，允许改为保存 |
| 贴图窗口创建失败 | 提示系统窗口数量限制 |

## 13. 隐私与安全

- 截图内容只在内存、剪贴板和本机文件中出现。
- 不写入日志；不上传到网络；不进入聊天记录，除非用户主动发送。
- 临时截图在取消后删除；发送后的缓存由现有缓存策略管理。
- 历史记录可一键清空。
- macOS 权限只申请屏幕录制，不申请无关权限。
- 截图 overlay 不应被其他应用轻易读取；但系统级截图工具仍可截到它，这是平台限制。
- 贴图窗口内容可能被其他屏幕录制软件捕获；如需要，可使用平台的内容保护能力（P1，且平台支持有限）。

## 17. 已确认的产品决策

1. 截图功能属于聊天主流程，但保持独立模块，可单独禁用。
2. 首版默认动作是进入标注，不是立即复制。
3. 发送复用现有图片发送链路，不新增协议。
4. 贴图是独立窗口，不嵌入聊天页面。
5. Wayland 接受“先系统截图、后 zchat 标注”的降级体验，并在界面明确说明。
6. 不将截图上传到任何服务器，历史记录仅本机保存。
