# zchat 功能清单

## 设备发现与状态

- 自动通过 UDP 组播和广播发现同一局域网中的 zchat。
- 显示设备名称、签名、头像、IP、端口、版本和平台。
- 在线设备排在离线设备之前。
- 支持在线、离开、忙碌、请勿打扰、隐身五种状态。
- 隐身时仍然保持连接，但对其他设备显示为离线。
- 手动输入 `IP` 或 `IP:端口` 连接无法自动发现的设备。
- 设备卡片右键可以发消息、设置备注、复制 IP、复制签名、移除离线设备。
- 可设置本地备注，替代设备原来的名称显示。

## 一对一聊天

- 文字消息，Enter 发送，Shift+Enter 换行。
- 图片消息，支持文件选择、拖入窗口和粘贴剪贴板图片。
- 文件消息，显示名称、大小、类型、下载进度。
- 消息撤回，限发送后 2 分钟内。
- 已发送、已送达、已读状态。
- 对方正在输入提示，4 秒无输入后自动消失。
- 未读角标，窗口不在前台时发送系统通知。
- 会话置顶、消息免打扰、清空记录、删除会话。
- 聊天记录搜索，按文本、文件名或发送者过滤。
- 消息右键菜单：复制、打开、在文件夹中显示、下载、复制下载链接、另存为、撤回、删除。
- 离线消息队列，对方上线后自动补发。

## 群聊

- 创建群聊并选择成员。
- 群聊名称、成员数、在线人数。
- 群聊信息窗口：改名、查看成员、添加成员、移出成员。
- 群主可以解散群聊；成员可以退出群聊。
- 群主、成员和“我”标签。
- 群系统消息：创建、邀请、改名、加人、移人、退出、解散。
- 群聊消息逐成员单播，不依赖服务器。
- 群消息和群操作也支持离线队列。

## 文件与图片

- 选择图片或文件发送。
- 拖放文件到窗口直接发送到当前会话。
- 从剪贴板粘贴图片发送。
- 图片自动下载并缓存，打开聊天即可查看。
- 图片按原始比例显示，过大的图片缩放后展示。
- 文件下载显示进度和总量。
- 下载完成后可直接打开或在文件夹中显示。
- 可另存为到指定位置。
- 重名文件自动追加序号，不覆盖已有文件。
- 发送者的本地路径不会泄露给接收方。

## 局域网文件共享

- 一键开启或停止 HTTP 文件共享。
- 选择任意目录作为只读共享目录。
- 目录网页适配手机，支持搜索和返回上一级。
- 隐藏以 `.` 开头的文件。
- 显示每个访问地址，可复制或在浏览器打开。
- 生成二维码，手机扫码即可访问。
- 可以把共享链接发送到当前会话。
- 显示共享端口、运行状态和目录。
- 防止 `..` 和符号链接逃逸共享目录。
- 附件通过不可猜测的令牌下载，令牌持久化。
- 关闭应用后共享链接失效。

## 外观与桌面集成

- 跟随系统、浅色、深色三种主题。
- 原生 MyGo UI，窗口使用隐藏标题栏和侧边栏毛玻璃。
- 系统托盘图标：打开窗口、切换状态、新建群聊、发现设备、文件共享、设置、检查更新、退出。
- 应用菜单：文件、编辑、会话、状态、窗口、帮助。
- 未读角标和托盘提示。
- 单实例锁，第二次启动会唤起已有窗口。
- 通知点击后打开对应会话。
- 关闭窗口时可按设置留在托盘。
- 常用快捷键：
  - `Cmd/Ctrl+F`：搜索会话
  - `Cmd/Ctrl+Shift+F`：搜索聊天记录
  - `Cmd/Ctrl+,`：设置
  - `Cmd/Ctrl+N`：新建群聊
  - `Cmd/Ctrl+Shift+N`：通过 IP 连接
  - `Cmd/Ctrl+O`：发送文件
  - `Cmd/Ctrl+Shift+M`：当前会话消息免打扰
  - `Esc`：关闭搜索或对话框

## 设置

- 个人资料：名称、签名、头像、状态。
- 头像选择后自动缩放并保存为 PNG。
- 外观主题。
- 新消息通知。
- 图片自动下载。
- 关闭窗口时留在托盘。
- 自动发现开关。
- TCP 监听端口和网络重启。
- 下载目录选择。
- 共享端口、启动时自动共享。
- 自动检查更新、自动下载安装、手动检查。
- 查看版本、项目主页、数据目录。

## 数据与可靠性

- 资料、会话、设备和离线队列保存为 JSON。
- 每个会话单独保存消息，减少写入放大。
- 原子写入，避免断电留下半个文件。
- 保存防抖，输入和连续消息不会频繁写盘。
- 退出前强制保存。
- 附件令牌持久化，重启后旧链接仍可下载。
- 图片缓存与临时粘贴图片独立存放。

## 更新与发布

- GitHub Releases 自动更新。
- 更新包使用 Ed25519 签名，已安装应用只接受匹配私钥的更新。
- 每天自动检查一次，也可手动检查。
- GitHub Actions 构建 macOS、Windows、Linux。
- Linux 提供 tar.gz、Debian 包和 PKGBUILD。
- Windows 提供 NSIS 安装器。
- macOS 提供 `.app` 与 `.dmg`。
- 发布说明从 `CHANGELOG.md` 对应版本段落生成。
