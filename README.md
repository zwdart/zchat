# zchat

zchat 是一个用 Go 和 [MyGo](https://github.com/egoist/mygo) 原生 UI 写的局域网聊天工具。所有消息都在同一局域网内的设备之间直接传输，不经过中心服务器。

## 功能

- **自动发现**：通过 UDP 组播与广播寻找同一局域网里的 zchat，支持手动输入 IP。
- **在线状态**：在线、离开、忙碌、请勿打扰、隐身，状态变化实时同步。
- **一对一聊天**：文字、图片、文件、撤回、已送达与已读状态、正在输入提示。聊天附件优先通过独立 TCP 端口直连传输，支持断点续传；TCP 不可用时自动回退到 HTTP，兼容旧版本。
- **群聊**：创建、邀请、改名、添加或移出成员、退出与解散。
- **局域网文件共享**：把本机目录通过 HTTP 只读共享，手机扫码即可用浏览器访问；也可以指定上传目录，让访客从网页上传文件。
- **图片与文件**：拖入窗口、粘贴剪贴板图片、图片自动缓存、下载进度与另存为。
- **桌面集成**：系统托盘、应用菜单、全局快捷键、未读角标、系统通知；点击消息头像或聊天标题头像可查看设备资料。
- **外观**：跟随系统、浅色、深色主题；界面支持简体中文和 English，可在设置里切换或跟随系统。
- **离线消息**：对方暂未在线时先保存在本机，连接后自动补发。
- **自动更新**：从 GitHub Releases 获取签名更新。

## 快速开始

需要 Go 1.27.3 或更新版本。

```bash
go test ./internal/...
go vet ./...
go run .

mygo build -platform darwin/universal,windows/amd64,linux/amd64
```

两台设备在同一个局域网内打开 zchat，就会在「发现设备」里互相出现。若网络屏蔽了广播，可以用「通过 IP 连接」输入对方的 `IP:42224`。

## 默认端口

| 用途 | 协议 | 端口 |
| --- | --- | --- |
| 设备发现 | UDP 组播/广播 | 42223 |
| 聊天连接 | TCP | 42224 |
| 文件传输 | TCP | 42225 |
| 目录共享 | HTTP | 42230 |

端口都可以在设置里修改。首次运行时如果系统防火墙询问是否允许 zchat 接收入站连接，请选择允许。

## 数据保存在哪里

- 配置文件：系统用户数据目录下的 `settings.json`
- 资料、会话、已知设备和离线队列：同目录下的 `state.json`
- 聊天记录：同目录下的 SQLite 数据库 `zchat.db`
- 图片缓存与未完成的下载：`cache/`
- TCP 文件传输令牌：`transfers-tcp.json`
- HTTP 附件令牌：`transfers.json`（用于 TCP 失败回退、旧版本和旧消息）

旧版本留下的 `messages/<会话 ID>.json` 会在第一次启动时自动导入数据库，原文件保留作备份。聊天记录可以在「设置 → 聊天记录」里查看大小、整理数据库或清空。

在「设置 → 关于 → 数据目录」可以直接打开。删除该目录会清空本机资料和聊天记录，不会影响其他设备。

## 安全说明

zchat 面向可信的局域网，协议本身不提供端到端加密，也不验证对方身份。请勿在公共 Wi-Fi 上传输敏感内容；需要跨不可信网络通信时，请先通过 VPN 或受控网络连接。

共享目录本身是只读的，访问者只能浏览和下载其中的文件；如果开启上传目录，知道共享地址的局域网访客可以把文件上传到该目录。请只在可信的局域网内开启上传。消息里的附件通过不可猜测的令牌从发送方直接下载；令牌会随会话记录保存在本机，发送方离线时无法下载。
